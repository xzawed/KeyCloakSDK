# 문서 구조 재편 + 정확성 가드 설계 (2026-07-23)

> <!-- doc-status: complete -->
> **✅ 완료 — 이 설계는 구현됐다. 기록으로 읽어라.** 여기 적힌 "할 것"은 이미 한 것이고, 결정의
> *근거*가 이 문서의 가치다. 지금 상태는 [CLAUDE.md](../../../CLAUDE.md) ·
> [문서 지도](../../README.md)에 있다.

`CLAUDE.md`가 135KB로 비대해져 **매 세션 컨텍스트를 잠식하고 지시 준수율을 떨어뜨리는** 문제, 그리고 문서가 코드와 조용히 어긋나도 **CI가 잡지 못하는** 문제를 함께 해결한다.

- 목표: 루트 `CLAUDE.md` **135KB → 약 33KB(-75%)**, 지식 손실 0, 드리프트를 CI에서 fail-closed 차단
- 방식: **제자리 압축 + 가산적 중첩**(스텁은 루트, 상세만 하위) + **앵커 기반 가드**

## 1. 측정된 문제

### 1.1 크기와 밀도

`CLAUDE.md` **134,169 B / 591줄** — 줄당 227B(긴 한글 산문 문단).

| 섹션 | 바이트 | 비중 |
|---|---|---|
| 현재 상태 | 59,449 | 44.3% |
| 핵심 게차 | 38,500 | 28.7% |
| 아키텍처 | 22,559 | 16.8% |
| 확정 의존성 | 8,037 | 6.0% |
| 문서 유지 규칙 | 1,772 | 1.3% |

⚠️ **위 표의 "현재 상태" 59,449B는 두 가지가 섞인 값이다.** 순수 서사는 40,313B이고, **나머지 19,121B는 9개 언어의 툴체인 빌드 명령 블록**(`### <Lang> 툴체인`)이 `## 현재 상태` 아래에 중첩된 것이다. 조사 초기 이 구분을 놓쳐 "툴체인 3,730B"로 잘못 집계했고, 그 상태로 "현재 상태를 통째로 삭제" 판단을 내렸다면 **9개 언어의 모든 빌드·테스트 명령이 사라졌을 것이다.**

### 1.2 게차는 74건이 아니라 84건

`## 핵심 게차` 아래 74건 + `## 현재 상태` 본문에 묻힌 10건(`gradle --stop` 금지, cargo-llvm-cov 인터랙티브 hang, `OPENSSL_CONF` 필요 등) = **84건**.

### 1.3 이력은 CHANGELOG에 중복되지 않는다

"이력은 어차피 CHANGELOG에 있으니 지우면 된다"는 가설은 **거짓으로 판명**됐다.

- PR #48·#62·#63·#67·#71은 `CLAUDE.md`에 3~9회 등장하고 `CHANGELOG.md`와 9개 검증로그 전부에 **0회**
- `CHANGELOG.md`는 아직 헤더에서 "8개 언어"라 말하며 Kotlin이 빠져 있다

→ **삭제가 아니라 이관**이어야 한다. 대상은 CHANGELOG(릴리스 대외 문서, 이미 드리프트)가 아니라 신규 `docs/governance/history.md`.

### 1.4 드리프트는 지금도 진행 중

2026-07-22 스윕에서 문서-빌드 대조를 9건 수행해 "불일치 0"을 확인했으나, **그 9건은 Java·Kotlin 의존성 표에 한정**이었다. 범위 밖에서 발견된 것:

| 문서 | 주장 | 실제 |
|---|---|---|
| `CLAUDE.md` | `Microsoft.IdentityModel.*` **8.19.2** | csproj **8.20.0** (PR #92가 만든 드리프트) |
| `docs/guides/getting-started.md` | Kotlin **2.2.20 or newer** | 실제 **2.4.10** |
| `docs/guides/getting-started.md` | `oauth2-oidc-sdk` **11.37.2** | 실제 **11.38.2** |

`getting-started.md`는 **사용자에게 나가는 설치 문서**다. 즉 검사 범위를 사람이 정하는 방식은 실패한다 — 가드가 필요한 근거.

### 1.5 근본 원인

전역 규칙 `~/.claude/CLAUDE.md`의 **"모든 작업이 완료되면 반드시 프로젝트 내 전체 문서를 최신화한다. 예외 없음."** 이 규칙이 매 PR마다 `CLAUDE.md`에 서사를 덧붙이게 한다. 비대화는 사고가 아니라 **규칙이 설계대로 작동한 결과**이며, 규칙을 그대로 두면 정리분은 재성장한다.

## 2. 확정된 제약 (공식 문서 검증)

세 경로(다중에이전트 워크플로·Grok 독립 검토·Claude Code 문서 검증)가 독립적으로 같은 결론에 도달했다. 출처: `code.claude.com/docs/en/memory`.

| 메커니즘 | 로드 시점 | 컨텍스트 절감 | 압축 후 재주입 |
|---|---|---|---|
| 루트 `CLAUDE.md` | 세션 시작, 전체 | — | **O** |
| 하위 `<dir>/CLAUDE.md` | 그 디렉터리 **파일을 읽을 때** | O | **X** |
| `@path` import | **세션 시작 시 인라인** | **X (전혀 없음)** | 루트와 동일 |

공식 권장치는 **200줄 이하**이며, 길수록 **지시 준수율 자체가 떨어진다**고 명시돼 있다. 게차를 많이 넣을수록 각 항목이 덜 지켜지는 역설이 성립한다.

## 3. 기각한 대안

### 3.1 언어별 완전 분할 (기각)

커밋 120건 분석 결과 **55%(66건)가 언어 디렉터리를 전혀 건드리지 않는다**(`harness/`·`.github/`·`scripts/`). 그런데:

- `harness/suites/<lang>.sh` 9개가 전부 루트 `CLAUDE.md`를 이름으로 참조
- 실제 결함 3건(ruby SimpleCov 오파싱·dotnet MSB1006 쉼표·sonar 4언어 배선)이 **언어 디렉터리 밖에서** 언어별 지식으로 수정됨
- 게차의 36%는 소속 언어 파일이 없다(교차언어 비교·harness·CI)
- 하위 파일은 압축 후 재주입되지 않는다

→ 소수(34%) 케이스를 최적화하고 다수를 악화시킨다.

### 3.2 `@path` import 분할 (기각)

§2 참조 — 컨텍스트 절감 0.

### 3.3 `.claude/rules/` (`paths:` 없이) (기각)

세션 시작 시 로드되어 루트와 동일 비용.

## 4. 목표 구조

### 4.1 루트 `CLAUDE.md` — 약 34KB (상향식 예산)

목표를 "총량에서 얼마를 뺀다"가 아니라 **각 섹션이 얼마를 쓸 수 있는가**로 정의한다. 하향식 뺄셈은 검증이 불가능하고, 실제로 이 설계의 초안에서 델타 합(−87KB → 47KB)과 선언한 목표(33KB)가 어긋났다.

| 현재 상태(상태표) | 1.5 KB | 10행 |

### 4.3 스텁/상세 분리 — 이 설계의 핵심

루트에 남는 형태:

> ⚠️ **(Kotlin) MockK로 JAX-RS 추상 클래스를 모킹하면 JDK 21에서 무기한 hang한다** → 실객체 사용. 상세: `kotlin/CLAUDE.md`

커밋 55%가 언어 디렉터리를 안 건드리므로 **상세는 자주 미로드**다. 그러나 **경보는 루트에 있어 항상 뜨고 압축 후에도 살아남는다.** 상세가 없어도 "여기 함정이 있다"는 사실은 놓치지 않으므로, **모르는 채 틀리는 실패 모드가 구조적으로 제거**된다.

### 4.4 내려보내지 않는 것

교차언어 비교 게차("9언어 중 node만 취약", "Java·Kotlin `resteasyClient`가 JacksonProvider 우회")와 harness·CI 게차는 소속 언어가 없다 → **루트에 원문 유지**.

### 4.5 서술 밀도

언어는 한글 유지, **산문 문단 → 불릿·표**로 전환해 밀도를 낮춘다(사용자 결정).

## 5. 정확성 가드

### 5.1 제약: 산문을 읽지 않는다

프로토타입 실측 — 휴리스틱 산문 스캔은 **11건 보고 중 대부분 오탐, 진짜 드리프트 2건을 둘 다 놓쳤다.** 구조화된 앵커만 읽는다.

### 5.2 앵커 — 좌표만 선언, 값은 저장하지 않는다

```markdown
<!-- doc-guard: kind=deps lang=kotlin source=kotlin/build.gradle.kts min=4 -->
| 의존성 | 좌표 | 버전 |
|---|---|---|
| Admin(재사용) | `org.keycloak:keycloak-admin-client` | 26.0.11 |
```

행 안의 백틱 좌표를 읽어 소스에서 추출·대조한다. 기대값을 스크립트에 적지 않으므로 **가드 자신이 드리프트할 수 없다.** 표를 옮기면 앵커도 함께 가고, 표를 지우면 매핑도 사라져 **고아 매핑이 불가능**하다.

### 5.3 fail-closed

`min=N`은 최소 추출 개수. 형식 변경으로 0개를 뽑으면 **통과가 아니라 실패**. CI는 매번 `checked N facts across M anchors`를 출력해 숫자 감소를 사람이 인지할 수 있게 한다.

### 5.4 검사 항목

대상은 `CLAUDE.md`만이 아니라 **버전을 주장하는 모든 `.md`**.

| # | 검사 | 실제 사건 포착 |
|---|---|---|
| 1 | 앵커된 버전 주장 ↔ 빌드 파일 | **현재 미해결 3건**(§1.4) 전부 |
| 2 | **문서 간 좌표 일치** | 과거 Java 표 11.37.2 ↔ Kotlin 표 11.38.1 (PR #96에서 수동 발견) |
| 3 | 최소 런타임 (`engines.node`·`rust-version`·`required_ruby_version`·`requires-python`·`TargetFramework`·`go` 지시자·`maven.compiler.release`·`jvmToolchain`) | 과거 "Node 20+" 잔존 (PR #87에서 수동 발견) |
| 4 | 커버리지 **게이트 임계값** (jacoco `<minimum>`·Kover `minValue`·vitest `thresholds`·SimpleCov·pyproject) | 미발생 |
| 5 | 마크다운 링크·헤딩 앵커 해석(`#c--net` 보호) | 미발생(현재 39개 링크 정상) |
| 6 | 기수 "9개 언어" ↔ `DEPLOY_LANGS`·9 SDK 디렉터리·9 스위트·9 CI | CHANGELOG의 "8개 언어" 잔존(§1.3) |

1~3번은 **이미 실제로 발생한 드리프트를 잡는다**(2·3번은 사람이 수동으로 찾아낸 것 — 가드가 있었다면 자동 포착). 4~6번은 예방적이다.

**2번은 문서에 버전이 하나도 없어도 표 간 모순을 잡는다.**

### 5.7 가드 자신의 부패 방지 — 변이 자가테스트

동결 픽스처에 대해 **셋 다 반드시 실패**해야 한다:

1. 셀 값 훼손 → 실패
2. 표 삭제 → 실패
3. 소스 비움 → 실패

하나라도 통과하면 가드가 no-op이 된 것이므로 그 사실로 CI가 죽는다.

### 5.8 도입 위험

- **CRLF**: `--fix`(문서 ← 소스 단방향) 출시 전 `.gitattributes`에 `*.md text eol=lf` 필요. 현재 `.md`가 미커버라 Windows에서 전체 CRLF diff 발생.
- **일괄 적색**: `repo-hygiene.yml`은 브랜치 필터 없는 `on: push`. 새 규칙을 fail-closed로 즉시 켜면 모든 Dependabot 브랜치가 동시에 빨개진다 → 검사 1·2번만 첫날 fail-closed, 나머지는 한 사이클 warn-only 후 승격.
- **`--fix` 세탁 위험**: 자동수정은 미검토 Dependabot 범프를 "문서화된 의도"로 만들 수 있다 → `--yes` 명시 요구, 단방향 고정.

## 7. G 이전 실증 프로브

중첩 파일의 가치는 로드 트리거에 달려 있는데, 공식 문서는 **파일 *읽기*가 트리거**라고만 하고 Bash 전용 턴을 명시하지 않는다. 이 저장소의 언어 작업은 `gradle -p kotlin test`처럼 Read 없이 시작하는 경우가 많다.

1. Read 없이 빌드 명령만 실행 → 해당 언어 파일이 로드되는가
2. `harness/apps/kotlin/…`을 읽었을 때 `kotlin/CLAUDE.md`가 로드되는가 (언어가 **3개 트리**에 분산: `kotlin/`·`harness/apps/kotlin/`·`harness/install/consume/kotlin-app/`)

2번이 부정이면 중첩 파일보다 **`.claude/rules/` + 다중 glob**이 낫다(`kotlin/**`·`harness/**/kotlin*/**`·`.github/workflows/kotlin-*.yml`). **G의 형태는 이 실측 후 확정한다.**
